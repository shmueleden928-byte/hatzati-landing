# דף הנחיתה של "הצעתי"

דף סטטי אחד. אין לו תלויות, אין בנייה — פותחים את `index.html` וזהו.

## חיבור הטופס לגוגל פורמס

הטופס לא שולח לשום מקום עד שממלאים שני ערכים בקובץ. עד אז הוא מציג הודעה
מפורשת שהוא לא מחובר, במקום להעמיד פנים שהפרטים נשמרו.

### 1. יוצרים טופס

ב־[forms.google.com](https://forms.google.com) יוצרים טופס חדש עם **שלוש שאלות
מסוג "תשובה קצרה"**, בסדר הזה:

1. שם
2. מקצוע
3. טלפון

### 2. משיגים את מזהי השדות

הדרך הקלה, בלי לקרוא קוד מקור:

1. בטופס: תפריט ⋮ (שלוש נקודות) ← **קבל קישור מלא מראש**
2. ממלאים ערכי דמה בשלוש השאלות: `AAA`, `BBB`, `CCC`
3. לוחצים **קבל קישור** ← **העתק קישור**

מקבלים כתובת בסגנון:

```
https://docs.google.com/forms/d/e/1FAIpQLSxxxxxxxx/viewform?entry.1111111=AAA&entry.2222222=BBB&entry.3333333=CCC
```

מתוכה:

- `1FAIpQLSxxxxxxxx` הוא מזהה הטופס
- `entry.1111111` הוא השדה של **שם** (כי שם היה `AAA`)
- `entry.2222222` הוא השדה של **מקצוע**
- `entry.3333333` הוא השדה של **טלפון**

### 3. ממלאים ב־`index.html`

מחפשים בקובץ את `CONFIGURE` (בתוך תגית ה־`<script>` בסוף) וממלאים:

```js
var FORM_ACTION = "https://docs.google.com/forms/d/e/1FAIpQLSxxxxxxxx/formResponse";
var FIELD_IDS = { name: "entry.1111111", trade: "entry.2222222", phone: "entry.3333333" };
```

שים לב: הכתובת מסתיימת ב־**`formResponse`**, לא ב־`viewform`. זו הכתובת שאליה
הטופס נשלח בפועל.

### 4. בודקים

פותחים את הדף, ממלאים, שולחים — ובודקים שהשורה הופיעה בגיליון התשובות של
הטופס. אם לא הופיעה, כמעט תמיד מזהה שדה שגוי או `viewform` במקום `formResponse`.

## הסכמה לדיוור — אל תיגע בזה

תיבת האישור בטופס אינה מסומנת מראש, וחוסמת שליחה כל עוד לא סומנה.

זה מכוון. סעיף 30א לחוק התקשורת אוסר שליחת דבר פרסומת בלי הסכמה מראש, וחל גם
על עסקים. הפיצוי הסטטוטורי מגיע עד ₪1,000 להודעה בלי הוכחת נזק. **רשימה שנאספה
בלי הסכמה מפורשת אי אפשר לשלוח אליה כלום** — לא עדכון השקה, לא את התבנית, כלום.
כלומר היא חסרת ערך.

סימון מראש של התיבה, או הסרת החסימה, הופכים את הרשימה מנכס לנטל משפטי.
